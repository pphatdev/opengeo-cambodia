# Geocoding & Address Normalization

This section explains how OpenGeo Cambodia translates raw GPS coordinates and unstructured search queries into canonical 4-tier Cambodian administrative divisions.

## Chapters in this Category
- **[05-geocoding-and-reverse-lookup.md](05-geocoding-and-reverse-lookup.md)**: Smart Reverse Geocoding & Address Autocomplete

## Key Concepts
- **Reverse Geocoding**: `/api/geocode/reverse?lat=...&lon=...` returning structured 4-tier hierarchy.
- **Normalization Cascade**: Harmonizing OpenStreetMap Nominatim tags into canonical Khmer administrative divisions.
- **Address Autocomplete**: Free-text search via `/api/geocode/search?q=...`.
