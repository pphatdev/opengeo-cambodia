# Getting Started with OpenGeo Cambodia

This section introduces the OpenGeo Cambodia platform, the historical address challenge in Cambodia, and the authoritative 4-tier administrative domain model.

## Chapters in this Category
- **[01-introduction-and-domain-model.md](01-introduction-and-domain-model.md)**: The Cambodia Address Problem & 4-Tier Administrative Model

## Key Concepts
- **Core Pillars**: Official MEF Open Data, 100% Free & Open Source (MIT), Sub-millisecond latency (< 1ms).
- **The 4 Tiers**: 25 Provinces (រាជធានី / ខេត្ត), 210 Districts (ស្រុក / ខណ្ឌ / ក្រុង), 1,661 Communes (ឃុំ / សង្កាត់), and 14,576 Villages (ភូមិ).
- **Dual Script**: Khmer native script (`name_km`) and standardized English Romanization (`name_en`).
