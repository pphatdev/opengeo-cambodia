## Source Data & License {#source-h}

The underlying administrative geographic data is officially sourced from the **Ministry of Economy and Finance Open Data Portal** ([data.mef.gov.kh](https://data.mef.gov.kh/)) and cross-referenced with NCDD codes.

The OpenGeo Cambodia API, frontend explorer, documentation, and data formatting pipelines are open-source software licensed under the permissive **[MIT License](https://github.com/pphatdev/opengeo-cambodia/blob/main/LICENSE)**. Feel free to use it in commercial applications, open source libraries, internal tools, and academic research.

Bug reports, missing villages, and feature requests are welcome on the [GitHub Issues tracker](https://github.com/pphatdev/opengeo-cambodia/issues).
