Knowledge Base & FAQ

Frequently Asked Questions

What is the Cambodian 4-Tier Administrative Model?

Cambodia's public administration follows a 4-level cascading hierarchy: Province / Capital (25) → District / Khan / Krong (210) → Commune / Sangkat (1,661) → Village (14,576).

How does OpenGeo achieve sub-1ms response times?

All administrative boundaries from the official National Committee for Sub-National Democratic Development (NCDD) dataset are pre-indexed into memory using $O(1)$ Hash Maps, completely eliminating database query overhead.

How does Reverse Geocoding work with OpenStreetMap?

GPS coordinates are matched against Nominatim and normalized through local rule cascades, accurately disambiguating nuances such as Phnom Penh Khans and provincial Krongs into standard 4-tier output.

Are Khmer script names supported alongside English?

Yes! Every division entity contains both native Khmer script (e.g. បន្ទាយមានជ័យ, ខណ្ឌដូនពេញ) and official Romanized English transliterations, with full-text search across both.
