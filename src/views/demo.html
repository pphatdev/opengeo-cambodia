Kingdom of Cambodia

Cambodia 4-Tier Administrative System

The Kingdom of Cambodia organizes territorial governance into four cascading administrative levels. OpenGeo Cambodia models each tier with standard government identification codes:

Tier 1 • ២៥ 2-Digit Code

Province & Capital

រាជធានី និង ខេត្ត (Khaet / Reach Theani)

24 Provinces and 1 Autonomous Municipality (Phnom Penh Capital). Codes range from 01 to 25.

Tier 2 • ២១០ 4-Digit Code

District, Khan & Krong

ខណ្ឌ ក្រុង និង ស្រុក (Srok / Krong / Khan)

162 Rural Districts (ស្រុក), 34 Municipalities (ក្រុង), and 14 Urban Khans (ខណ្ឌ) in Phnom Penh.

Tier 3 • ១,៦៦១ 6-Digit Code

Commune & Sangkat

សង្កាត់ និង ឃុំ (Khum / Sangkat)

1,405 Rural Communes (ឃុំ) and 256 Urban Quarters / Sangkats (សង្កាត់).

Tier 4 • ១៤,៥៧៦ 8-Digit Code

Villages

ភូមិ (Phum)

Foundational human settlements across rural and urban Cambodia, mapped directly to parent communes.

package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

type ApiResponse struct {
    Success bool             `json:"success"`
    Data    []map[string]any `json:"data"`
}

func main() {
    // 1. Fetch Cambodia 25 Provinces (<1ms in-memory cache)
    resp, err := http.Get("https://opengeo-cambodia.pphat.me/api/admin/provinces")
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()

    var result ApiResponse
    if err := json.NewDecoder(resp.Body).Decode(&result); err == nil {
        fmt.Printf("Loaded %d provinces successfully\n", len(result.Data))
    }
}

val client = OkHttpClient()

use reqwest;
use serde_json::Value;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let base_url = "https://opengeo-cambodia.pphat.me";

    // 1. Fetch all 25 Provinces (<1ms edge response)
    let resp: Value = reqwest::get(format!("{}/api/admin/provinces", base_url))
        .await?
        .json()
        .await?;

    if let Some(provinces) = resp["data"].as_array() {
        println!("Loaded {} provinces successfully", provinces.len());
    }

    // 2. Reverse Geocode Coordinates

        .await?
        .json()
        .await?;

    println!("Location: {} / {}", geo["district"], geo["province"]);
    Ok(())
}

Frequently Asked Questions

Common questions regarding Cambodia administrative boundaries, geography queries, and OpenGeo API usage.

01. What is OpenGeo Cambodia and its purpose?

OpenGeo Cambodia is an open API for Cambodia geography data designed around three core pillars:

  1. Administrative Hierarchy: Complete coverage across all 4 official tiers (25 Provinces, 210 Districts, 1,661 Communes, and 14,576 Villages).
  2. Allow users to use for free: 100% free and open-access under the MIT license with zero API keys and no paywalls.
  3. Provide fast response time: Sub-1ms (<1ms) in-memory query speed with zero database overhead.
02. How many provinces and administrative tiers exist in Cambodia?
Cambodia is divided into 4 official administrative tiers: 1) Tier 1 has 25 Provinces (ខេត្ត) including the capital municipality Phnom Penh (រាជធានី); 2) Tier 2 has 210 Districts (ស្រុក), Municipalities (ក្រុង), and Khans (ខណ្ឌ); 3) Tier 3 has 1,661 Communes (ឃុំ) and Sangkats (សង្កាត់); and 4) Tier 4 has 14,576 Villages (ភូមិ).
03. Does OpenGeo Cambodia support both Khmer script and English Romanization?
Yes. Every administrative entity includes its official Khmer name in Khmer script (e.g., រាជធានីភ្នំពេញ, ដូនពេញ), standardized Latin English transliteration (e.g., Phnom Penh, Doun Penh), and official administrative code. The search endpoint matches both interchangeably.
04. How fast is the OpenGeo Cambodia cascading lookup?
OpenGeo Cambodia delivers sub-1ms (<1ms) response times for administrative lookups by leveraging an optimized in-memory indexed data store and edge-ready Cloudflare Workers / Node.js architecture.
05. How does reverse geocoding work in Cambodia with OpenGeo?
By providing latitude and longitude coordinates (e.g. 11.5564, 104.9282), OpenGeo queries OpenStreetMap Nominatim and normalizes the raw GPS location into the standardized 4-tier Cambodian administrative hierarchy (Province → District → Commune → Village).
06. Is OpenGeo Cambodia free to use for commercial projects?
Yes, OpenGeo Cambodia is 100% free and open-source under the MIT license for developers, fintech applications, delivery logistics, NGOs, and businesses across Cambodia.
